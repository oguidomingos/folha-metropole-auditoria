2. Ingestão

  • Coletores: feedparser p/ RSS; trafilatura (extração de texto limpo) + httpx; Playwright/patchright só para sites com JS; API oficial quando existir (Câmara, Senado, BCB, IBGE).
  • Frequência: RSS a cada 10–15 min (cron do n8n); sites HTML a cada 30–60 min; DOU 1×/dia 08h; Google News queries a cada 30 min.
  • Detecção de novidade: ETag/Last-Modified + hash do guid/url canônico (UTM removido).
  • Dedupe em 3 camadas: (1) URL canônica; (2) hash do título normalizado; (3) embedding cosseno ≥ 0,88 nas últimas 72h → mesmo "cluster de evento"; o agente escreve 1 matéria por cluster usando todas as fontes do cluster (reduz risco de plágio e melhora fact-check).
  • Robustez: robots.txt respeitado, User-Agent identificado, rate-limit por domínio, retry com backoff, alerta no Telegram se fonte ficar 24h sem item.

4. Agente gerador

Fluxo (LLM em 4 passos):

  1. Triagem/score (modelo barato): relevância p/ o perfil do FM (editoria, região, utilidade), urgência, risco (crime, menores, saúde, eleição) → define se vai para humano obrigatório.
  2. Extração de fatos: lista estruturada de afirmações (quem, o quê, quando, onde, números, citações) com ID da fonte → grava em article_claims.
  3. Redação (modelo forte) a partir dos fatos, não do texto-fonte: prompt de estilo com few-shot de 5–8 matérias reais do FM por editoria, regras da seção 1.4 (título 80–110 chars, linha fina, lead 5W, H2 a cada 2–3 parágrafos, 450–900 palavras, "nesta terça-feira (9)", sem adjetivo, sem opinião; crédito da fonte no texto: "segundo a Agência Senado"). Saída em JSON: titulo, linha_fina, corpo_md, slug, tags, meta_desc, imagem_sugerida, legenda.
  4. Verificação: (i) outro passe LLM confere cada número/nome/data contra claims; (ii) checagem de similaridade vs. textos-fonte (n-grams 8-gram overlap < 15% e cosseno do embedding do parágrafo) — reprova se copiou; (iii) filtros: nada de acusação sem "segundo a polícia/denúncia", presunção de inocência, sem nome de menor, sem informação médica prescritiva.
  • Direito autoral: só reescrita factual a partir de fontes de uso permitido (tabela §1) + crédito; fotos só de agência pública/release/IA rotulada; nunca copiar foto de portal comercial.
  • Conflito de interesse: lista de entidades do Charles (leadagencybrazil, facipan, mudavida, adapta, agbank etc.) → matéria que as cite vai para revisão obrigatória com nota de divulgação.
  • Colunas/opinião: fora do escopo automático (autoria humana).

5. Três entregas

(a) Post de blog — publicação automatizada

  • POST /wp-json/wp/v2/posts com Application Password de um usuário "Redação Automática" (role Author/Editor), status=draft ou future (agendado), categories, tags (criar via /tags), excerpt=linha fina, slug, meta Rank Math (rank_math_title, rank_math_description, rank_math_focus_keyword via meta/endpoint do plugin).
  • Imagens: upload POST /wp/v2/media (nome=slug), alt, caption = "Foto: <crédito>", featured_media.
  • Corpo em blocos do Gutenberg (H2, parágrafos) com shortcode/bloco do banner Mercado Livre inserido após o 2º parágrafo.
  • Pré-requisito: Gooweb liberar a REST na Cloudflare para a VPS [bloqueador #1]. Plano B: XML-RPC (/xmlrpc.php) ou plugin leve com endpoint próprio assinado por HMAC.

(b) Carrossel/foto Instagram

  • Templates HTML/CSS (Poppins, #00334d/#ff9900, logo do FM) renderizados em PNG por Playwright/satori: capa 1080×1350 (4:5) com manchete em até 3 linhas sobre foto escurecida + tarja de editoria; 3–6 cards de texto (1 fato por card, ≤ 35 palavras); card final com CTA "Leia a matéria completa — link na bio" + selo de fonte.
  • Variante "card único" 1080×1350 para plantão.
  • Geração de imagem por IA apenas como fallback de fundo (editoria sem foto), sempre rotulada "Ilustração: IA"; nunca para fatos reais/crimes/pessoas reais.
  • Legenda (≤ 2.200 chars) + hashtags + crédito da foto. Publicação via Instagram Graph API (/media carousel children + /media_publish) — exige conta Business + Page + app Meta em modo live [token a obter]. Enquanto isso: pacote ZIP + legenda na fila para postagem manual.

(c) Vídeo/Reels — A CONFIRMAR com o Guilherme (proposta)

  • Roteiro 30–45 s gerado do artigo aprovado (gancho 3 s → 3 fatos → fechamento).
  • Narração: ElevenLabs (voz PT-BR) ou OpenAI TTS (mais barato); legendas via Whisper Groq (alinhamento).
  • Montagem: Remotion (React → MP4, 1080×1920) com a mesma identidade visual: fotos com zoom (Ken Burns), manchete animada, legenda queimada, trilha livre; alternativa mais rápida: FFmpeg + templates.
  • Publicação via Graph API (media_type=REELS). Custo/tempo maior; recomendo fase 3 após validar (a) e (b).
